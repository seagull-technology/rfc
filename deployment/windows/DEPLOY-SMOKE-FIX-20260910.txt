RFC maintenance smoke-check correction - 2026-09-10

PURPOSE
Windows PowerShell's HTTP transport matches CookieContainer cookies against an
explicit Host header. The previous loopback cookie was therefore omitted from
the request to Host filmjordan.jo, causing Laravel's maintenance response (503).
The signed cookie itself matches Laravel's validation requirements.

The corrected helper sends that cookie explicitly on a request to 127.0.0.1,
with no CookieContainer, proxy or automatic redirects. Public maintenance stays
active until sign-in returns HTTP 200 and the queue worker is checked. HTTP
errors and redirects still fail deployment; response objects are disposed.
This helper also includes the managed IIS worker-query correction.
