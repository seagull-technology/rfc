RFC GOVERNMENT SERVER UPGRADE CHECKLIST
=======================================

Before running the deployment:

1. Ask the database administrator to create a snapshot/backup of FSStgMDLDB.
2. Confirm C:\inetpub\rfc\.env exists and contains the current production secrets.
3. Reconcile the server .env against:

   deployment\windows\.env.production.example

   Keep every key only once. Preserve the existing APP_KEY, database credentials,
   GSB credentials, and seeded account credentials rather than copying placeholders.
   Confirm these non-secret values are present:

   APP_ENV=production
   APP_DEBUG=false
   APP_URL=https://filmjordan.jo
   ASSET_URL=https://filmjordan.jo
   APP_TIMEZONE=Asia/Amman
   TRUSTED_PROXIES=10.0.40.81
   TRUSTED_HOSTS=filmjordan.jo
   TRUSTED_HOSTS_ENFORCE=true
   SECURITY_HEADERS_ENABLED=true
   SECURITY_CSP_REPORT_ONLY=false
   SECURITY_HSTS_ENABLED=true
   SECURITY_HSTS_MAX_AGE=31536000
   SECURITY_PROFILE_URL_ALLOWED_HOSTS=imdb.com,linkedin.com,filmfreeway.com,vimeo.com,youtube.com
   SECURITY_WEBSITE_URL_ALLOWED_HOSTS=filmjordan.jo
   SECURITY_OUTBOUND_HTTP_ALLOWED_HOSTS=api-gateway.stg.gsb.gov.jo,bulk-sms.gov.jo,signflow.sanad.gov.jo
   SESSION_SECURE_COOKIE=true
   SESSION_ENCRYPT=true
   SESSION_HTTP_ONLY=true
   SESSION_SAME_SITE=lax
   SESSION_DOMAIN=null
   OTP_DEBUG_FALLBACK=false
   GOV_SMS_CONNECT_TIMEOUT=5
   GOV_SMS_TIMEOUT=15
   GOV_SMS_TOKEN_CACHE_SECONDS=45
   FILESYSTEM_LOCAL_SERVE=false
   GSB_ENABLED=true
   GSB_ENVIRONMENT=stg
   GSB_BASE_URL=https://api-gateway.stg.gsb.gov.jo:9443
   GSB_CREW_VERIFICATION_MINUTES=120
   GSB_MOHE_UNDERGRADUATE_ENABLED=true
   GSB_MOHE_UNDERGRADUATE_PATH=/porg-g2g/g2g/api/LastSemester
   GSB_MOHE_UNDERGRADUATE_METHOD=POST
   GSB_CCD_COMPANY_ENABLED=true
   GSB_CCD_COMPANY_PATH=/porg-g2g/g2g/api/companies/CompanybyNo/{nationalNo}
   GSB_CCD_COMPANY_METHOD=GET
   GSB_MIT_SERVICES_ENABLED=true
   GSB_MIT_SERVICES_PATH=/porg-g2g/g2g/api/Registry/getIndividualRegistry
   GSB_MIT_SERVICES_METHOD=GET
   GSB_CSPD_MASKED_ENABLED=true
   GSB_CSPD_MASKED_PATH=/porg-g2g/g2g/masked/api/person-info
   GSB_CSPD_MASKED_METHOD=GET
   GSB_CSPD_MASKED_PSD_PATH=/porg-g2g/g2g/masked/api/psd
   GSB_PSD_BASIC_INFO_ENABLED=true
   GSB_PSD_BASIC_INFO_PATH=/porg-g2g/g2g/token/psd
   GSB_PSD_BASIC_INFO_METHOD=POST
   GSB_SIGNFLOW_V2_ENABLED=true
   GSB_SIGNFLOW_V2_PATH=/porg-g2g/g2g/signflow/v2
   GSB_SIGNFLOW_V2_METHOD=POST
   GSB_SIGNFLOW_V2_OPEN_ENABLED=true
   GSB_SIGNFLOW_V2_OPEN_PATH=/porg-g2g/g2g/signflow/v2
   GSB_SIGNFLOW_V2_OPEN_METHOD=POST

   Keep GSB_SIGNFLOW_V2_ENABLED and GSB_SIGNFLOW_V2_OPEN_ENABLED false until
   the RFC callback URL is registered in the Sanad portal. The user's browser
   is redirected directly to the documented SignFlow authorization endpoint;
   the RFC server does not call the SignFlow public host. Then set:

   SANAD_SIGNFLOW_BASE=https://signflow.sanad.gov.jo
   SANAD_REDIRECT_URI=https://<public host>/ar/sign-in/sanad/callback
   SANAD_CULTURE=ar

4. Keep the real GSB_CLIENT_ID and GSB_CLIENT_SECRET values already stored in .env.
   Add the OAuth bearer supplied for PSD BASIC INFO Token as:

   GSB_PSD_BASIC_INFO_BEARER=<provider bearer token>

   Keep GSB_CSPD_TOKEN_ENABLED=false for the Personal Details Form. That token
   product returns the identity represented by its bearer and does not accept the
   form's arbitrary national number as an input.

   Store the SignFlow portal ApiKey and SecretKey as SANAD_CLIENT_ID and
   SANAD_CLIENT_SECRET. GSB_CLIENT_ID and GSB_CLIENT_SECRET remain the
   X-IBM header credentials for server-side GSB calls.

   Preserve the real GOV_SMS_USER, GOV_SMS_PASS, and provider-approved
   GOV_SMS_HEADER values. If GOV_SMS_PASS contains a # character, wrap the
   complete value in single quotes in .env so Laravel does not treat the rest
   of the password as a comment. Before OTP UAT, confirm /authenticate returns
   HTTP 200 and a token; HTTP 400 is a provider credential/account response,
   not a network-access failure.
5. Confirm APP_URL, ASSET_URL, and SANAD_REDIRECT_URI use the final HTTPS public
   host. The current RFC IIS logs identify 10.0.40.81 as the reverse proxy, so
   keep TRUSTED_PROXIES=10.0.40.81 unless IT changes that topology. Leave it
   empty only for direct IIS/NAT traffic. Confirm the proxy strips the generic
   Forwarded header and
   emits only filmjordan.jo in any X-Forwarded-Host header; IIS and Laravel both
   reject other forwarded hosts.

   Review SECURITY_PROFILE_URL_ALLOWED_HOSTS and
   SECURITY_WEBSITE_URL_ALLOWED_HOSTS with the RFC business owner. Add only
   domains that users genuinely need; do not use wildcard or generic CDN hosts.
   Keep SECURITY_OUTBOUND_HTTP_ALLOWED_HOSTS limited to the government API,
   SMS, and SANAD hosts approved by MODEE. HTTP redirects are disabled by the
   application clients, so any provider endpoint change must be reviewed here.

   The IIS site needs an HTTPS binding with a certificate that includes its
   private key. A .crt file alone is not sufficient unless the matching CSR and
   private key were generated on this Windows server. Verify:

     Get-ChildItem Cert:\LocalMachine\My |
       Where-Object { $_.Subject -match "filmjordan" } |
       Select-Object Subject, Thumbprint, HasPrivateKey, NotAfter

   HasPrivateKey must be True before creating the IIS HTTPS binding.
6. Confirm C: has enough free space for the new release and one full application backup.
7. Confirm C:\php\php.ini contains expose_php=Off, display_errors=Off,
   log_errors=On, upload_max_filesize=10M, and post_max_size=16M. The upload
   limits must cover the application's 10 MB registration document and optional
   2 MB logo. For production performance, also confirm Zend OPcache is enabled.
   Verify the effective PHP configuration with:

     C:\php\php.exe -r "echo ini_get('expose_php') ? 'FAIL' : 'OK';"
     C:\php\php.exe -r "echo 'upload_max_filesize='.ini_get('upload_max_filesize').PHP_EOL.'post_max_size='.ini_get('post_max_size');"
     C:\php\php.exe -r "echo (extension_loaded('Zend OPcache') && (bool) ini_get('opcache.enable')) ? 'OPCACHE OK' : 'OPCACHE DISABLED';"

   The security check must print OK and the upload values must be at least 10M
   and 16M. The deployment script will stop before extracting the release if
   PHP version disclosure is enabled or upload limits are too small, and will
   warn when OPcache is disabled.
8. Confirm IIS static and dynamic compression are installed. Run PowerShell as
   Administrator if they are missing:

     Enable-WindowsOptionalFeature -Online `
       -FeatureName IIS-HttpCompressionStatic,IIS-HttpCompressionDynamic `
       -All -NoRestart
9. Complete deployment/windows/SECURITY-RETEST.md with the network owner before
   the security retest. Confirm the public TLS terminator rejects TLS 1.0/1.1,
   CBC and static-RSA suites; all gateway cookies have the required attributes;
   untrusted Host inputs are rejected before DNS or routing; and egress is
   restricted to the approved destinations. Application checks alone cannot
   establish these results.
10. Run PowerShell as Administrator.

The release must be built with production dependencies only:

  composer install --no-dev --classmap-authoritative

Build browser assets on the build machine with the locked npm dependencies:

  npm run build
  npm run vendor:check

Include public/js/lodash.min.js and public/js/lodash.LICENSE.txt in the archive,
retain the SHA-256 output, and clear gateway caches for the old JavaScript asset.

The deployment script runs `php artisan security:production-check` before any
database migration. It will reject debug mode, OTP debug fallback, insecure or
parent-domain cookies, HTTP application URLs, Laravel Boost, the browser logging
endpoint, direct private-filesystem serving, and missing authentication
rate-limit middleware. It then writes a versioned dependency SBOM and control
manifest under the private local disk at storage\app\private\security-evidence.

Deployment command example:

  Set-ExecutionPolicy -Scope Process Bypass
  C:\Deploy\rfc-offline-release-20260909-v1\Deploy-RfcRelease.ps1 `
    -ArchivePath C:\Deploy\rfc-offline-release-20260909-v1\rfc-app.tar.gz `
    -ExpectedSha256 "VERIFIED_64_CHARACTER_APP_ARCHIVE_SHA256"

Use the rfc-app.tar.gz hash from the verified release's SHA256SUMS.txt. The script
rejects a mismatch before extraction. Run from C:\inetpub, outside the app folder.
RFCQueueWorker must be installed. Its command must use the absolute path
C:\inetpub\rfc\artisan queue:work without --force. The scheduler name defaults to
RFC Laravel Scheduler; pass -SchedulerTaskName if the installed task differs.

The script preserves .env and current storage, pauses writers before its final
storage copy, applies migrations, swaps the application, rebuilds caches without
clearing the shared application cache, and checks the sign-in page while public
maintenance remains active. It starts and checks the worker before reopening.
The site must serve C:\inetpub\rfc\public and must not share its application pool
with another running website. An already-maintained application is rejected.

Reference lookups and roles are preserved by default. Use -SeedAccessControl only
when a release includes a reviewed seed change; this security release does not.

Do not delete the generated C:\inetpub\rfc-backup-* directory until UAT is complete.

For a newly created worker, ONLY after Deployment completed successfully:

  Set-Service -Name RFCQueueWorker -StartupType Automatic
  Get-Service -Name RFCQueueWorker

PASSWORD RECOVERY QUEUE (V06)
- Configure QUEUE_CONNECTION=database (or an approved durable async queue).
- Set DB_QUEUE_RETRY_AFTER=180 for the documented 120-second worker timeout.
- Native Windows does not provide Laravel's PCNTL timeout enforcement. Keep
  GOV_SMS_CONNECT_TIMEOUT=5 and GOV_SMS_TIMEOUT=15; start with one worker.
- If the service is missing, use the bundled Install-RfcQueueWorker.ps1 with a
  verified NSSM 2.24-101+ executable stored outside the app directory. Setup
  leaves the limited service account's worker Stopped with Manual startup.
- Confirm the managed RFCQueueWorker service restarts after queue:restart.
- Verify a controlled account receives its reset OTP and the queue drains.
- Never use sync/deferred/background delivery in production.
